# Keyboard

This is a Zig 0.16.0 application I'm working on. It currently supports
My Machine (Debian 13), so your results may vary.

## AI Disclosure

I used an LLM to help with Linux audio config, importing third party C
libraries, and generating throwaway scripts to make sure audio output was
working. I have no plans to use LLMs for stuff that I want to do, but fully
reserve the right to use them to do things that I don't want do.
